4 · Deletion (denied by default)

    
The cognee.forgetDataset capability is irreversible. VICT denies it
    unless the run carries an explicit { policy: { allowIrreversible: true } }. This demo holds that switch
    server-side, never in the page. Deletion is only demonstrated on the disposable demo stores.
